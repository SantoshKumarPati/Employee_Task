# Employee Task Management System

## Project Description

The Employee Task Management System is a web application used to create,
manage, assign, and track employee tasks.

## Technologies Used

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- REST API
- MySQL
- JPA / Hibernate
- Git and GitHub

## Features

- Employee Login and Logout
- Dashboard with task statistics
- Add new tasks
- Edit tasks
- Delete tasks
- Assign tasks to employees
- Change task status
- Search tasks by title
- Filter tasks by status
- Filter tasks by priority
- Task due-date validation
- MySQL database persistence
- REST APIs
- Responsive user interface

## Task Information

Each task contains:

- Title
- Description
- Priority
- Status
- Due Date
- Assigned Employee

## Task Status

- Pending
- In Progress
- Completed

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or another Java IDE.
3. Create a MySQL database named `employee_tasks`.
4. Configure the MySQL username and password in `application.properties`.
5. Run `TaskManagementApplication.java`.
6. Open the application in a browser.

## Application URL

http://localhost:8081/login.html
